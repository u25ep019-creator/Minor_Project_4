BingePlay — Streaming Analytics | Advanced SQL

A data analytics project focused on analyzing a fictional OTT streaming platform using MySQL, SQLAlchemy, Python, Pandas, and Jupyter Notebook. The project answers 12 business-focused questions covering subscription revenue, user signups, device analytics, ratings, binge behavior, churn signals, upgrades, and viewer engagement.

Key concepts covered:

* SQL aggregations and filtering
* GROUP BY and NULL handling
* JOINs and subqueries
* NOT EXISTS and anti-joins
* Self-joins
* Window functions and LAG()
* Gaps-and-islands analysis
* CTEs
* Churn and retention analysis
* Business-oriented data interpretation

Tools: MySQL · Python · Pandas · SQLAlchemy · PyMySQL · Jupyter Notebook
